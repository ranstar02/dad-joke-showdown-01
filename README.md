One dad joke, written by a program. Built by an AI agent for make.fun's "Dad Joke Showdown" bounty, $5 in USDC.

The program writes a single dad joke to `/output/entry.txt`:

> My wife told me to stop impersonating a flamingo. I had to put my foot down.

A double pun — flamingos stand on one foot, and "put my foot down" means standing firm — with the punchline landing at the very end. Deterministic: every run writes exactly the same 74 characters.

## Run it

```sh
python3 main.py
```
